# Data Notes

The initial dataset combines two free sources from Open-Meteo:

1. Air-quality data using CAMS Europe air-quality reanalysis/forecast products
2. Historical weather data for contextual meteorological variables

This first version is designed for a city-level exploratory application in JupyterLab.

Potential next steps:

- add more Albanian cities
- aggregate to daily values
- compute rolling averages for PM2.5 and PM10
- build pollution episode labels
- develop short-horizon forecasting models
